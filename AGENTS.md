# AGENTS.md

The instruction file every coding agent working on this repository reads. It carries the rules
that are **enforced by CI**, plus a map to where everything else lives. Keep it small; detail
belongs in [`docs/`](docs/README.md).

## What this project is

Everything that executes a composable outside an IDE: the Jetpack Compose renderer (Android, via
Robolectric), the Compose Multiplatform Desktop renderer (via `ImageComposeScene`), the data
extractors that read semantics, layout, fonts, resources and the rest off a rendered frame, and
the long-lived **render daemon** that hosts a sandbox pool and speaks JSON-RPC to the tools and
the preview server. Extracted from [yschimke/compose-ai-tools](https://github.com/yschimke/compose-ai-tools)
— [`docs/design/DAEMON_SPLIT.md`](docs/design/DAEMON_SPLIT.md) records the boundary and why.

```
0  compose-preview-contracts   wire shapes two repositories must agree on as bytes
1a compose-preview-daemon      THIS: renderers, data extractors, the hosts, the daemon process
1b compose-ai-tools            discovery, the Gradle plugin, the CLI, bundles, history, render-host
2  compose-preview-server      HTTP, the web surfaces, the UI builder
```

A module may depend on a strictly lower layer and on nothing else. Nothing here may reach
`compose-ai-tools` or the server; a shape the daemon and the server must agree on across a process
boundary goes to `compose-preview-contracts`, never here.

## The CI-enforced invariants

### Git history must never attribute work to an AI agent

Non-negotiable. Commits are attributed solely to the human committer. Two things are rejected:

1. a `Co-authored-by:` trailer, at trailer position, naming an agent (Claude / Codex / ChatGPT /
   Copilot / Gemini) or using an agent email; and
2. a commit whose **author or committer identity** is an agent — an `@anthropic.com` /
   `@openai.com` email, or an agent **name** set as the identity.

GitHub App bot accounts (`…[bot]`) are exempt from (2) but not from (1). Explicitly **fine**: links
to an agent session (`claude.ai/code`), the "🤖 Generated with …" and `_Generated by [Claude Code]_`
footers, and ordinary PR comments. **Scrub the PR description too**: the gate scans title and body.

Enforced by one detector ([`.github/scripts/agent-attribution-scan.sh`](.github/scripts/agent-attribution-scan.sh))
in three places: the [`commit-msg`](.githooks/commit-msg) and [`pre-push`](.githooks/pre-push)
hooks and the [`No Agent Attribution`](.github/workflows/no-agent-attribution.yml) CI gate. Install
the hooks with [`scripts/install-git-hooks.sh`](scripts/install-git-hooks.sh); Claude Code's
`SessionStart` hook runs it, every other agent runs it itself. `Yuri Schimke <yuri@schimke.ee>` is
this repository's human identity; reviewers run the scanner before reporting an attribution finding.

### Branch names are always `agent/…`

Never `claude/…`, `copilot/…`, `codex/…` or any other agent prefix.

### Conventional commits for PR titles and commit subjects

`fix:`, `feat:`, `perf:`, `docs:`, `ci:`, … PRs are squash-merged, so the squashed commit carries the
**PR title only** — release-please reads that. A `!` in a title does **not** bump the major: every
release here is a minor ([`pr-title.yml`](.github/workflows/pr-title.yml) rejects the marker).

### Run the formatter before committing

CI's `ktfmtCheckAll` is a hard gate. Before each commit touching `*.kt` / `*.kts`, run
`./gradlew ktfmtFormatAll` (or `./gradlew :<module>:ktfmtFormat`) and stage the result.

### The published surface

Every module under `api/`, `daemon/`, `data/`, `renderers/` and `runtimes/` publishes to Maven
Central under `ee.schimke.composeai` at the release tag, on **one** version line. Modules that
declare `abiValidation()` pin their public API in a committed dump; `checkKotlinAbi` runs in CI, and
a public-surface change is committed with `./gradlew updateKotlinAbi`.
`docs/daemon/TUNABLES.md` is generated from `DaemonProperties`; `DaemonPropertiesDocTest` fails
when it is stale.
Dependency versions are maintained in `gradle/libs.versions.toml`; this repository does not use
Gradle dependency locking.

### Dependency ownership is enforced on production runtimes

`checkDependencyOwnership` resolves JVM, KMP/JVM, and every Android production-variant runtime
classpath, including transitives. Project components in this build and the exact lower-layer
`compose-preview-contracts` coordinates are allowed; every other external
`ee.schimke.composeai:*` module is tools/server-owned and forbidden. `checkHttpServerFloor` also
rejects embedded HTTP engines. PR CI invokes both tasks explicitly; update the policy and its
build-logic regression tests together.

### Re-check PR state immediately before every push

`git fetch origin main` and confirm the branch head is not already in `origin/main`. If the PR has
merged, stop: branch fresh for the follow-up.

## PR workflow

- **Open a PR automatically when a coding task is finished, committed and pushed.** Check first
  whether the branch already has an open PR and push to it rather than opening a duplicate.
- **A PR that changes what a renderer draws carries before/after evidence as embedded images from a
  GitHub-hosted origin** (`raw.githubusercontent.com`, commit-pinned). Text-only is correct for a
  non-visual change.
- **Don't auto-merge.** Opening, tracking and fix-up commits are automatic; merging is the user's
  call.
